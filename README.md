# ヘヤカルテ

内見に行く前に、部屋の「まわり」まで分かる部屋探しアプリ。
大学進学で初めて一人暮らしをする人のために、スーパーや病院までの距離、家の前の車の多さ、災害のリスク、毎月のお金を1枚の「カルテ」にまとめ、親への相談文までAIで作ります。

チームHの「人生の転換点」ハッカソン提出物です（予選 2026-09-25、本選 2026-09-26）。

## ペルソナと機能の対応

| ペルソナ | 機能 |
| --- | --- |
| 西日本出身・大阪の大学に進学 | 通う大学を選ぶと、キャンパスからの距離で部屋を並べる（今は近畿大学 東大阪キャンパス） |
| 内見がめんどくさい | 条件入力の代わりに4つの質問に答えるだけ。候補は3件ずつ。「オンライン内見でこれだけ聞けばOK」リストを物件ごとに作る |
| 奨学金で通う | 奨学金・仕送り・バイトから家賃の目安を出し、毎月の残りと入居前の費用を計算。奨学金の初回振込が入学後であることも伝える |
| スーパーや病院の位置を知りたい | 徒歩5分・10分の輪つきの地図と、最寄りのスーパー・診療所・病院・夜間救急 |
| 周辺の交通量を知りたい | 家の前の道の種類と、近くの幹線道路・線路から車の量を5段階で表示 |
| 災害の情報も押さえたい | 洪水の浸水想定・土砂災害警戒区域・津波・今後30年の地震の確率・避難場所 |
| 親の関与あり | 親が気にする5項目（家賃・初期費用・防犯・災害・病院）の判定と、LINEに貼れる相談文をAIが作る |

## 画面

はじめに → お金 → 質問 → 候補 → カルテ（地図／暮らし／交通量／災害／お金／なぜこの順位？） → 内見チェック → 親に相談

すべて1画面に収まり、縦スクロールせずに「次へ」で進みます。

## 動かし方

```bash
python3 -m http.server 8765
```

`http://localhost:8765` を開きます。`index.html` を直接開くと `data/area.json` を読めないので、必ずサーバー経由で開いてください。

公開版は Claude Artifact として動かしていて、そこでは AI（Claude）が使えます。AI が使えない環境では、キーワードでの読み取りとひな形の文章で同じ流れが動きます。

## 周辺データの作り方

```bash
pip install pillow
python3 scripts/build_area.py
```

`scripts/build_area.py` が下記のオープンデータを取得し、物件ごとの周辺情報を計算して `data/area.json` に書き出します。取得結果は `scripts/.cache/` に保存し、2回目以降は再利用します。

物件そのもの（名前・家賃・間取りなど）は**デモ用の架空データ**です。位置だけ実在の住宅地に置いています。
徒歩の分数は「直線距離 × 1.3」を80m/分（不動産の表示に関する公正競争規約の基準）で割った目安です。
交通量は道路の種類からの推定で、実際に測った値ではありません。

## 使ったOSS・オープンデータ

| 名前 | ライセンス | 使い方 |
| --- | --- | --- |
| [Leaflet](https://github.com/Leaflet/Leaflet) 1.9.4 | BSD-2-Clause | 地図の表示。CDN（cdnjs）から読み込み、CSSは `vendor/leaflet.css` をページに埋め込み |
| [OpenStreetMap](https://www.openstreetmap.org/copyright)（Overpass API 経由） | ODbL | 駅・スーパー・コンビニ・ドラッグストア・診療所・病院・道路・線路 |
| [国土地理院 重ねるハザードマップ](https://disaportal.gsi.go.jp/) | 出典明記で利用可 | 洪水浸水想定区域（想定最大規模）・土砂災害警戒区域・津波浸水想定 |
| [国土地理院 指定緊急避難場所データ](https://www.gsi.go.jp/bousaichiri/hinanbasho.html) | 出典明記で利用可 | 洪水のときの避難場所 |
| [J-SHIS 地震ハザードステーション](https://www.j-shis.bosai.go.jp/)（防災科学技術研究所） | 出典明記で利用可 | 今後30年に震度6弱以上・5強以上の揺れに見舞われる確率 |

## ファイル

- `index.html` … アプリ本体（1ファイル）
- `data/area.json` … 物件と周辺情報、地図用の道路データ
- `scripts/build_area.py` … `data/area.json` を作るスクリプト
- `vendor/leaflet.css` … Leaflet のCSS（`index.html` に埋め込んだものの元）
