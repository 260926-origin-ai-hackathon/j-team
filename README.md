# ヘヤカルテ

内見に行く前に、部屋の「まわり」まで分かる部屋探しアプリ。
大学進学で初めて一人暮らしをする人のために、スーパーや病院までの距離、家の前の車の多さ、災害のリスク、毎月のお金を1枚の「カルテ」にまとめ、親への相談文までAIで作ります。

チームHの「人生の転換点」ハッカソン提出物です（予選 2026-09-25、本選 2026-09-26）。

## ペルソナと機能の対応

| ペルソナ | 機能 |
| --- | --- |
| 西日本出身・大阪の大学に進学 | 知らない街でも、地図で大学（今は近畿大学 東大阪キャンパス）のまわりのどこが住みやすいかが分かる |
| 内見がめんどくさい | 条件を入力せず、地図を見て気になる場所の物件をタップするだけ。「オンライン内見でこれだけ聞けばOK」リストを物件ごとに作る |
| 奨学金で通う | 奨学金・仕送り・バイトから家賃の目安を出し、毎月の残りと入居前の費用を計算。奨学金の初回振込が入学後であることも伝える |
| スーパーや病院の位置を知りたい | 地図にスーパー・コンビニ・ドラッグストア・診療所・病院を重ねる。物件を選ぶと徒歩5分・10分の輪と最寄りの施設を表示 |
| 周辺の交通量を知りたい | 地図の道路を車の量で色分け。物件ごとに家の前の道と近くの幹線道路・線路から5段階で表示 |
| 災害の情報も押さえたい | 地図に洪水の浸水想定区域（50m四方）と避難場所を重ねる。物件ごとに建物の場所とすぐ近く（50m以内）の浸水想定、土砂災害、津波、地震の確率 |
| （全部まとめて） | ヒートマップ：総合・買い物・病院・静かさ・通学・浸水しにくさのテーマで、エリアのどこが住みやすいかを色で表示 |
| 内見に行かずに建物の質を知りたい | 家の材質（木造・軽量鉄骨造・鉄骨造・RC造・SRC造）と、音の伝わりにくさ・火事への強さ、築年数から推定した耐震基準（旧耐震／新耐震／木造の2000年基準）を「建物」タブに表示 |
| 親の関与あり | 親が気にする5項目（家賃・初期費用・防犯・災害・病院）の判定と、LINEに貼れる相談文をAIが作る |

## 画面

場所から探す2画面の構成です。どちらも1画面に収まり、縦スクロールしません。

1. **地図**：ヒートマップ・スーパー・病院・交通量・浸水想定・避難場所を切り替えて重ね、物件の金額の札をタップすると右側に概要が出る。右上の「家賃の目安」で奨学金・仕送り・バイトを入れると、予算オーバーの札が薄くなる
2. **詳しい住宅情報**（「詳しく見る」か、同じ札をもう一度タップ）：左に物件のまわりの地図、右にタブ（建物／暮らし／交通量／災害／お金／内見で聞くこと／親に相談）。交通量・災害のタブでは、左の地図も車の量・浸水想定の表示に切り替わる

### ヒートマップの計算

地図全体を80m四方のマスに区切り、マスの中心から次の距離を測って0〜1の点にします。テーマごとにエリア内の下位5%〜上位5%を0〜1に広げて色を付けるので、色は「このエリアの中での比較」です。

- 買い物：いちばん近いスーパー（150mで満点、900mで0点）とコンビニ
- 病院：いちばん近い診療所と病院
- 静かさ：幹線道路・やや広い道路・線路からの距離
- 通学：キャンパスの出入口までの距離
- 浸水しにくさ：洪水の浸水想定の深さ
- 総合：上の5つの平均

## 動かし方

### Docker（おすすめ）

```bash
docker compose up -d --build
```

`http://localhost:8080` を開きます。止めるときは `docker compose down`。

周辺データを作り直すとき（OpenStreetMap・国土地理院・J-SHIS から取得し直して `data/area.json` を上書き）:

```bash
docker compose --profile data run --rm data
```

作り直したあとは `docker compose up -d --build` でアプリに反映します。

### Docker を使わない場合

```bash
python3 -m http.server 8765
```

`http://localhost:8765` を開きます。`index.html` を直接開くと `data/area.json` を読めないので、必ずサーバー経由で開いてください。

公開版は Claude Artifact として動かしていて、そこでは AI（Claude）が使えます。AI が使えない環境（Docker やローカル）では、親への相談文はひな形の文章になり、それ以外はすべて同じように動きます。

## 周辺データの作り方

```bash
pip install pillow
python3 scripts/build_area.py
```

`scripts/build_area.py` が下記のオープンデータを取得し、物件ごとの周辺情報を計算して `data/area.json` に書き出します。取得結果は `scripts/.cache/` に保存し、2回目以降は再利用します。

## データの確かさ

画面でも、情報ごとに「実データ／推定／独自の目安／一般的な傾向／架空」の印と出典を出しています（右上の「データについて」に一覧があります）。

| 情報 | 種類 | 中身 |
| --- | --- | --- |
| 物件（名前・家賃・間取り・構造・階数・築年数） | 架空 | デモ用に作ったデータ。位置だけ実在の住宅地に置いている |
| スーパー・病院・駅・道路・線路 | 実データ | OpenStreetMap。ボランティアが作る地図なので、載っていない店もある |
| 洪水の浸水想定 | 実データ | 国土地理院 洪水浸水想定区域（想定最大規模）。1000年に1度くらいの大雨で川があふれた場合の想定で、過去の実績や予報ではない。**内水氾濫（側溝・下水があふれる浸水）は含まない**。地図は50m四方ごとに中心の1点を読み取っている |
| 土砂災害・津波・避難場所 | 実データ | 国土地理院 |
| 地震の確率 | 実データ | J-SHIS 確率論的地震動予測地図（2020年版）、250m四方の値 |
| 交通量 | 推定 | 道路の種類からの推定。実際に測った交通量ではない |
| 徒歩・自転車の分数 | 推定 | 直線距離×1.3を、徒歩80m/分（不動産の表示に関する公正競争規約の基準）・自転車250m/分で割った目安 |
| 耐震基準 | 推定 | 築年数（架空）から、建った年を逆算して推定 |
| ヒートマップ | 独自の目安 | 公開データから距離で点数を付けたもの。線引きは独自の基準で、色はエリア内の相対値 |
| 構造ごとの特徴・生活費・初期費用 | 一般的な傾向 | 一般的な目安 |

| [国土地理院 指定緊急避難場所データ](https://www.gsi.go.jp/bousaichiri/hinanbasho.html) | 出典明記で利用可 | 洪水のときの避難場所 |
| [J-SHIS 地震ハザードステーション](https://www.j-shis.bosai.go.jp/)（防災科学技術研究所） | 出典明記で利用可 | 今後30年に震度6弱以上・5強以上の揺れに見舞われる確率 |

## ファイル

- `index.html` … アプリ本体（1ファイル）
- `data/area.json` … 物件（22件）と周辺情報、地図用の道路データ、浸水想定のマス
- `scripts/build_area.py` … `data/area.json` を作るスクリプト
- `vendor/leaflet.css` … Leaflet のCSS（`index.html` に埋め込んだものの元）
- `Dockerfile`・`docker/nginx.conf`・`docker-compose.yml` … Docker で配信する設定（nginx）と、データを作り直すコンテナ
