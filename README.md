# ヘヤカルテ

内見に行く前に、部屋の「まわり」まで分かる部屋探しアプリ。
大学進学で初めて一人暮らしをする人のために、スーパーや病院までの距離、家の前の車の多さ、災害のリスク、毎月のお金を1枚の「カルテ」にまとめ、親への相談文までAIで作ります。

チームHの「人生の転換点」ハッカソン提出物です（予選 2026-09-25、本選 2026-09-26）。

**デモ：https://heyakarte.vercel.app** （ログインなしで開けます。AI で親への相談文を作る機能は Claude Artifact 版でだけ動き、ここではひな形の文章になります）

## 使用技術

| 分類 | 使ったもの | どこで使っているか |
|---|---|---|
| 画面 | HTML・CSS・JavaScript（フレームワークなし・ビルドなし、`index.html` 1ファイル） | すべての画面。画面の切り替えは URL の `#` で行う |
| 地図 | [Leaflet](https://leafletjs.com/) 1.9.4 | 地図・物件の札・ヒートマップ・重ねる情報。背景タイルは使わず、OpenStreetMap の道路を線で描く |
| 3D | [three.js](https://threejs.org/) 0.180.0 | 部屋の中の3D表示と家具の配置（jsDelivr から読み込む） |
| AI | Claude（Claude Artifact の `sample` 機能） | 親への相談文を整える（Artifact 版のみ） |
| 周辺データの作成 | Python 3・Pillow・NumPy | `scripts/build_area.py`。道のり（道路網の最短経路）、騒音、ハザード、犯罪件数を計算して `data/area.json` を作る |
| 遮音の計算 | [python-acoustics](https://github.com/python-acoustics/python-acoustics)（BSD-3、必要な関数だけ取り込み） | 壁の材質から遮音性能（Rw）を計算 |
| データ | OpenStreetMap（Overpass API）・国土地理院・J-SHIS・大阪府警・Geolonia 住所データ | 詳しくは「使ったOSS・オープンデータ」 |
| 公開 | Vercel（静的ホスティング）・Claude Artifact | デモの公開 |
| 開発環境 | Docker（nginx・Python） | 手元での表示とデータの作り直し |
| 開発 | Claude Code | 設計・実装・データ処理 |

| 周辺の交通量を知りたい | 地図の道路を車の量で色分け。物件ごとに家の前の道と近くの幹線道路・線路から5段階で表示 |
| 災害の情報も押さえたい | 地図に洪水の浸水想定区域（50m四方）と避難場所を重ねる。物件ごとに建物の場所とすぐ近く（50m以内）の浸水想定、土砂災害、津波、地震の確率 |

| （全部まとめて） | ヒートマップ：総合・買い物・病院・静かさ・通学・浸水しにくさ・防犯・飲食店・コンビニ・バス停のテーマで、エリアのどこが住みやすいかを色で表示 |

| 親の関与あり | 親が気にする5項目（家賃・初期費用・防犯・災害・病院）の判定と、LINEに貼れる相談文をAIが作る |

## 画面

「キャラ → 地図 → 住宅詳細」の順に進みます。どの画面も1画面に収まり、縦スクロールしません。

0. **最初の画面**：案内役のキャラクター「ヘヤまる」（水色の家の形。カルテを持っている）とアプリ名「ヘヤカルテ」だけを大きく出す（上のボタン類も出さない）。ヘヤまるをタップすると地図へ。左上のロゴを押すといつでもこの画面に戻る。`#map` や `#home-〇〇` のリンクで開いたときは、その画面から始まる
1. **地図**：右下のヘヤまるが、選んだ物件の「いいところ」「気になるところ」を表情つきで話す（ヒートマップのテーマや重ねる情報を変えたときも、数秒だけひとこと）。地図の下のタスクバー（「地図に重ねる」「ヒートマップ」「凡例」）をタップすると、そのカテゴリの中身が開く。ヒートマップのテーマや、スーパー・病院・飲食店・バス停・交通量・浸水想定・避難場所・防犯を切り替えて重ね、物件の金額の札をタップすると右側に概要が出る。右上の「家賃の目安」で奨学金・仕送り・バイトを入れると、予算オーバーの札が薄くなる
2. **詳しい住宅情報**（「詳しく見る」か、同じ札をもう一度タップ）：物件名と家賃のあいだで、ヘヤまるが開いているタブと評価に合わせた表情（にっこり・考え中・困り顔・びっくり）でひとこと話す。左に物件のまわりの地図、右にタブ（部屋の中（3D）／建物／暮らし／交通量／災害／防犯／お金／内見で聞くこと／親に相談）。最初は「部屋の中（3D）」が開き、左側が3Dの部屋になる。交通量・災害・防犯のタブでは、左の地図も車の量・浸水想定・犯罪の件数の表示に切り替わる
3. **お気に入り**（右上の「☆ お気に入り」）：地図の右側と住宅詳細の「☆ お気に入り」（スター）で入れた物件をカードで並べ、家賃・予算との差・大学やスーパー・病院までの分数・建物／暮らし／交通量／災害／防犯／お金の評価を見くらべる。入れた順・家賃が安い順・大学に近い順に並べかえられ、カードから住宅詳細や地図へ移れる（住宅詳細の「戻る」はお気に入りへ）。地図の札にも ★ が付く。お気に入りはこの端末（localStorage）に保存

### 色

コンセプトカラーは水色。キャラクター「ヘヤまる」と同じ4段階の水色で組んでいる。

| 役割 | カラーコード |
| --- | --- |
| 主な色（ボタン・選択中の札・タブの下線など。白い文字を乗せても読める濃さ） | `#2A7AB8` |
| 濃い水色（キャラの輪郭・アプリ名） | `#1E5F8A` |
| 水色（キャラの屋根・飾り） | `#3F9FD8` |
| 明るい水色（キャラの体） | `#8FD3F4` |
| 淡い水色（最初の画面の背景・予算のバッジなど） | `#E3F4FC` |
| 文字 | `#17283A` |
| 画面の背景 | `#EDF3F8` |

ヒートマップの5段階（赤〜緑）、防犯の紫、浸水想定の青など、意味を持つ色は変えていない。暗い画面（ダークモード）では主な色を `#6BBEEA` にする。

### ヒートマップの計算

地図全体を80m四方のマスに区切り、マスの中心ごとに0〜1の点を付けます。「総合」以外は決まった基準で点を付けるので、別の日に見ても同じ色になります。

点は20点刻みで5段階に分け、どこでも同じ記号・言葉・色で表します。

| 点 | 記号 | 言葉 | 色 |
| --- | --- | --- | --- |
| 0.8以上 | ◎ | とても良い | 緑 |
| 0.6〜0.8 | ○ | 良い | 黄緑 |
| 0.4〜0.6 | △ | ふつう | 黄 |
| 0.2〜0.4 | ▲ | やや悪い | 橙 |
| 0.2未満 | × | 悪い | 赤 |

序列が読み取れるように、次の3か所で同じ5段階を使っています。

- 凡例：5段階と、エリアのうちそれぞれの段階が占める割合（例：◎とても良い 37%）。「良い」でも上位半分に入らないことがある理由が分かる
- 地図の上：カーソル（スマホではタップ）の地点の段階、エリアの中で上位何%か、実際の値（スーパーまで約380mなど）
- 物件の概要：7テーマそれぞれの段階・上位何%か・実際の値の表

距離はすべて**道のり**です。OpenStreetMap の道路・歩道・階段（約4万4千の点、5万6千本の区間）をたどった最短距離を、データ作成時に計算しています（`scripts/build_area.py` の `WalkGraph`）。線路や大きな道路の向こう側は、踏切や横断できる場所まで回り込んだ距離になります。

- 買い物：いちばん近いスーパー（道のり200m以内で満点、1.1km以上で0点）とコンビニ
- 病院：いちばん近い診療所（200m〜1km）と病院（400m〜1.8km）
- 静かさ：屋外の騒音の推定値（50dB以下で満点、68dB以上で0点）。計算方法は下の「騒音と遮音の計算」
- 通学：キャンパスの出入口までの道のり（400m〜3km）
- 浸水しにくさ：洪水の浸水想定の深さ
- 飲食店：いちばん近い飲食店（レストラン・カフェ・ファストフード。道のり150m〜800m）と、400m以内の軒数（20軒で満点）を半分ずつ
- コンビニ：いちばん近いコンビニまでの道のり（100m〜600m）
- バス停：いちばん近いバス停までの道のり（150m〜800m）
- 防犯：マスの中心から500m以内に代表点がある町丁目の、1年間の犯罪の件数（物件の「防犯」タブと同じ数え方）。エリア内の下位10%〜上位10%で「少ない〜多い」
- 総合（あなた向け）：ほかの9テーマの重み付き平均。テーマごとに「気にしない（0）／ふつう（1）／大事（3）」を選べ、選ぶと「あなた向け」に切り替わる。「おすすめ」はペルソナに合わせて買い物・浸水しにくさ・防犯を「大事」にした設定。平均すると差が小さくなるので、エリア内の下位5%〜上位5%を0〜1に広げて比べる。選んだ重みはブラウザに保存する

### 部屋の中（3D）

[kurashi-ai](https://github.com/daichi05xxx-commits/kurashi-ai)（daichi05xxx-commits）の3D内見を移植しています（`index.html` の `window.Room3D`）。

- 取り込んだもの：間取りタイプ別のテンプレート（`src/lib/layouts.ts` の 1R・1K・1DK）と、専有面積に合わせた組み立て・壁の当たり判定、three.js の部屋・窓の向きによる日差し・操作（`src/components/Walkthrough3D.tsx`）
- 取り込んでいないもの：周辺の道路・騒音マップ・交通量の3D表示・家具の配置（ヘヤカルテ側に同じ役割の機能があるため。家具を置いて試す機能はヘヤカルテ側で別に作った）
- three.js 0.180.0 は、3Dのタブを開いたときに jsDelivr から読み込む
- **家具を置いて試す**（ヘヤカルテで追加）：3Dタブの「家具を置く」で、ベッド・学習机・本棚・冷蔵庫・洗濯機・テレビ台・ローテーブル・ソファ・衣装ケース、または幅×奥行（cm）を入れた自分の家具を置ける。空いている場所に自動で置き、ドラッグで動かす・90°回す・消すができる。壁に当たる・部屋からはみ出す・ほかの家具と重なるときは一覧に ⚠ で出す。置いた内容はブラウザ（localStorage）に物件ごとに保存。部屋の寸法は目安なので、実寸は内見や図面で確かめる前提
- 操作：ドラッグで見まわす／床をクリックでそこまで歩く／W A S D・矢印キー・左下のスティックで移動／右の間取り図をタップで瞬間移動／「上から見る」で間取り全体を見る
- 3Dは間取り図から読み取ったものではなく、間取りタイプと面積から組み立てた簡易モデル。窓の向き・バルコニーはデモ用の架空データ（物件の id から決める）

### 騒音と遮音の計算

`scripts/build_area.py` で計算して `data/area.json` に入れています。どれも**推定**です。

1. **屋外の騒音**：道路の種類ごとに「道路の端から10mでの昼間の騒音」を仮定し（幹線道路70dB、やや広い道路60dB、生活道路44〜48dB、線路65dB。幹線道路70dB・住宅地55dBという騒音の環境基準を目安にした値）、道路を20mごとの点に分けて、距離による減衰と建物による遮へい（最大15dB）を見込んで足し合わせます。騒音地図のOSS（NoiseModelling など）と同じ「音源を点に分けてエネルギーで足す」考え方を、ごく簡単にしたものです。
2. **壁と窓の遮音**：構造ごとに一般的な壁の材料を仮定し（例：木造の隣との壁は石膏ボード12.5mm×2、RC造は鉄筋コンクリート180mm）、材料の重さから質量則で1/3オクターブごとの透過損失を出し、ISO 717-1 の評価値（Rw、車の音向けの Rw+Ctr）にします。計算には python-acoustics の関数を使っています（`scripts/acoustics_building.py`）。
3. **隣の部屋の音**：隣との壁の Rw から、床や天井を回り込む分（木造・軽量鉄骨造5dB、鉄骨造6dB、RC造・SRC造10dB）を引いて、5dB刻みのD値の目安にします。結果は木造D-30、軽量鉄骨造D-35、鉄骨造D-40、RC造・SRC造D-50です。
4. **部屋の中の騒音**：屋外の騒音から、外壁と窓（アルミサッシの単板ガラス5mm、窓の割合30%）を合わせた遮音を引きます。窓がいちばんの弱点なので、構造による差は小さくなります。

## 動かし方

### Docker（おすすめ）

```bash
docker compose up -d --build
```

`http://localhost:8080` を開きます。止めるときは `docker compose down`。

周辺データを作り直すとき（OpenStreetMap・国土地理院・J-SHIS から取得し直して `data/area.json` を上書き）:

```bash
docker compose --profile data run --rm data
```

作り直したあとは `docker compose up -d --build` でアプリに反映します。

### Vercel（公開中のデモ）

`https://heyakarte.vercel.app` に置いています。配信するのは `index.html` と `data/` だけです（`.vercelignore`）。作り直すときは、Vercel にログインした状態で次を実行します。

```bash
npx vercel deploy --prod
```

### Docker を使わない場合

```bash
python3 -m http.server 8765
```

`http://localhost:8765` を開きます。`index.html` を直接開くと `data/area.json` を読めないので、必ずサーバー経由で開いてください。

公開版は Claude Artifact として動かしていて、そこでは AI（Claude）が使えます。AI が使えない環境（Docker やローカル）では、親への相談文はひな形の文章になり、それ以外はすべて同じように動きます。

## 周辺データの作り方

```bash
pip install pillow numpy
python3 scripts/build_area.py
```

`scripts/build_area.py` が下記のオープンデータを取得し、物件ごとの周辺情報を計算して `data/area.json` に書き出します。取得結果は `scripts/.cache/` に保存し、2回目以降は再利用します。

## データの確かさ

画面でも、情報ごとに「実データ／推定／独自の目安／一般的な傾向／架空」の印と出典を出しています（右上の「データについて」に一覧があります）。

| 情報 | 種類 | 中身 |
| --- | --- | --- |
| 物件（名前・家賃・間取り・構造・階数・築年数） | 架空 | デモ用に作ったデータ。位置だけ実在の住宅地に置いている |
| スーパー・病院・駅・道路・線路 | 実データ | OpenStreetMap。ボランティアが作る地図なので、載っていない店もある |
| 洪水の浸水想定 | 実データ | 国土地理院 洪水浸水想定区域（想定最大規模）。1000年に1度くらいの大雨で川があふれた場合の想定で、過去の実績や予報ではない。**内水氾濫（側溝・下水があふれる浸水）は含まない**。地図は50m四方ごとに中心の1点を読み取っている |
| 土砂災害・津波・避難場所 | 実データ | 国土地理院 |
| 犯罪の発生 | 実データ（加工） | 「犯罪発生情報（2025年）」（大阪府警察 犯罪オープンデータ）を加工して作成。自転車盗・オートバイ盗・ひったくり・車上ねらい・部品ねらい・自動販売機ねらい・自動車盗の7手口で、**空き巣などの侵入盗や性犯罪は含まない**。発生は町丁目単位なので、町丁目の代表点（Geolonia 住所データ）が物件から500m以内のものを数えている |
| 交番・警察署 | 実データ | OpenStreetMap |
| 地震の確率 | 実データ | J-SHIS 確率論的地震動予測地図（2020年版）、250m四方の値 |
| 交通量・屋外の騒音 | 推定 | 道路の種類ごとの仮定値から計算。実際に測った交通量・騒音ではない |
| 隣の部屋の音・部屋の中の騒音 | 推定 | 構造ごとに一般的な壁の材料を仮定し、質量則で計算した目安。実際の建物では窓・すき間・床からの回り込みで変わる |
| 徒歩・自転車の分数 | 推定 | OpenStreetMap の道路・歩道・階段をたどった道のりを、徒歩80m/分（不動産の表示に関する公正競争規約の基準）・自転車250m/分で割った目安。地図に載っていない近道は反映されない |
| 耐震基準 | 推定 | 築年数（架空）から、建った年を逆算して推定 |
| ヒートマップ | 独自の目安 | 公開データから距離で点数を付けたもの。線引きは独自の基準で、色はエリア内の相対値 |
| 構造ごとの特徴・生活費・初期費用 | 一般的な傾向 | 一般的な目安 |
